03 / MEASUREMENT

Compare the same work.

Run each browser at the same viewport, resolution, workload, and observation period. Capture the browser app and its WebContent/GPU/network processes. Page JavaScript cannot accurately measure total process CPU or RAM.

Camera, mic, peer connections, workers, audio contexts, and GPU resources have explicit cleanup. Hidden pages stop live captures. Use Stop all resources before recording the idle baseline.

For physical iPads, serve this page over trusted HTTPS. The iPad simulator can use the Mac's localhost server, but simulated devices and location do not prove physical hardware behavior.
